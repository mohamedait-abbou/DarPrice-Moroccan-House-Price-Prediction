# DarPrice Model Card

## Model details

| Item | Value |
|---|---|
| Model | XGBoost regressor inside a scikit-learn `Pipeline` (full tuning available via `src/train.py`) |
| Task | Regression: predict a Moroccan house sale price in MAD |
| Target | `log1p(price)` (inverted with `expm1` at inference) |
| Inputs | city, neighborhood, property_type, condition, area, rooms, bathrooms, floor, age, amenities_count |
| Derived features | `area_per_room`, `rooms_plus_bath`, `amenities_per_100m2`, `is_new` |
| Training data | 7,014 cleaned listings from two public Moroccan property sources |
| Split | 80% train / 20% held-out test, `random_state=42` |
| Selection | Best 5-fold shuffled CV MAE on the training set only |
| Artifact | `models/darprice_model.joblib` (full pipeline) |

## Intended use

- Educational and portfolio demonstrations of an end-to-end ML system.
- Quick, indicative estimates for a listing when the user supplies the same
  fields the model was trained on.
- Comparing relative prices across cities, property types, and sizes.

## Out-of-scope use

- Formal property valuation, mortgage decisions, or legal/financial advice.
- Listings outside Morocco or outside the covered cities/neighborhoods.
- Inputs that were not present at training time (for example, a new city is
  ignored by the one-hot encoder and the prediction falls back to the global
  pattern).
- Detecting fraud, discrimination, or market manipulation.

## Training data

Two scraped sources are merged and cleaned:

1. `houses_data_eng.csv` — 4,675 rows, but only 24 unique feature combinations
   after deduplication (the same listings repeat).
2. `morocco_houses_dataset.csv` — 10,000 rows; only `transaction == "vente"` is
   kept.

After cleaning: **7,014 rows × 11 columns**. Leakage columns (`price_per_sqm`,
`reference`, `description`, `listing_date`) are removed. Outliers are filtered
with market sanity bounds (price > 50,000 MAD, area ≥ 10 m², price/m² between
2,000 and 80,000 MAD). See `data/README.md` for the full schema.

## Evaluation

The final metrics are stored in `metrics.json` and `models/metadata.json`.
The model is selected by cross-validation on the training set, then evaluated
**once** on the held-out test set.

Reported metrics:

- **MAE** — average absolute error in MAD (easy to explain to a user).
- **RMSE** — penalizes large errors more strongly.
- **R²** — fraction of price variance explained.
- **MAPE / within-20%** — relative error, useful because cheap and expensive
  houses should not be compared on the same absolute scale.

Error analysis is regenerated by `python -m src.evaluate` and written to
`reports/` (per-city, per-property-type, worst predictions, and charts).

## Limitations

- **Synthetic/scraped data quality.** The sources are small and contain
  duplicates and templated listings. Metrics may be optimistic compared with a
  real, noisy production feed.
- **Coverage.** Only 11 Moroccan cities are represented. Neighborhood coverage
  is uneven; rare neighborhoods are mostly ignored by the encoder.
- **Missing fields.** `condition` and `age` are missing for source 1; the
  pipeline imputes them.
- **No temporal validation.** Listings are not split by date, so the model does
  not measure how well it would forecast future market prices.
- **No uncertainty estimate.** The API returns a point estimate, not a
  confidence interval.
- **Distribution shift.** A new city, unusual property type, or very different
  market conditions can produce unreliable estimates.

## Ethical considerations

- Property prices can correlate with protected characteristics through
  neighborhood features. The model should not be used to make decisions that
  affect people's access to housing.
- Always show the estimate as an indicative range/point estimate, not a
  guaranteed valuation.
- Do not use the model to justify discriminatory pricing or redlining.

## Reproducibility

- Pinned dependencies in `requirements.txt`, `requirements-train.txt`, and
  `requirements-dev.txt`.
- Fixed seed (`42`), recorded in `metrics.json`.
- Committed processed dataset and model artifact.
- `metrics.json` records Python, scikit-learn, XGBoost, pandas, and numpy
  versions.
