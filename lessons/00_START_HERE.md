## 👤 Who is this for?

You. Someone who:
- Knows a little Python but not the libraries (pandas, sklearn...)
- Wants to READ and EDIT all files of this project alone
- Wants to build OTHER projects alone after this
- Learns slowly = learns DEEPLY. This is good. Fast learners forget. Slow learners keep.

## 📏 The rules of this course

1. **Do NOT skip.** Each lesson uses the one before it.
2. **Type the exercises yourself.** Do not copy-paste. Your fingers learn too.
3. **A quiz you get wrong is GOOD.** Wrong answers teach more than right ones.
4. If confused, re-read. Confusion is normal. It melts after the 2nd or 3rd read.
5. One lesson per day maximum. Sleep makes learning stick.
